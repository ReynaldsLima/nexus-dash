**Wiring:** 9 connected, 1 orphaned (`/insights`), 1 missing (SET-01)

### Key findings

1. **`app/[tenant-slug]/layout.tsx` gating** — confirmed correct for both `tenant_admin` and `agency` roles post-fix, no regression from Phase 5's additions.
2. **Custom Access Token Hook (0005 → 0019)** — confirmed the agency branch addition doesn't drop `tenant_id`/`tenant_slug` for plain Cliente users; original branch preserved verbatim as the `ELSE` fallback.
3. **`app/api/meta-ads/connect/route.ts`** — confirmed today's `getClaims()` fix is correctly in place and this route was never affected by the `getUser().app_metadata` bug in the first place (it used `get_user_role()` RPC for the role gate, a different, unaffected code path).
4. **Leads page/API composition** — no Phase 5 fork of the leads page exists; agency and Cliente share the exact same UI. `GET /api/leads`'s implicit-RLS-only protection is the one architectural inconsistency (see AGENCY-08 partial, above).
5. **Dangling `viewer` role** — no active code path found; all remaining references are the documented rollback-safety-net type-widening already tracked in STATE.md, or test/migration-comment mentions. Confirmed, not a new finding.

### New findings from this audit (not previously tracked anywhere)

- **F1 (SET-01 confirmed unimplemented)** — see Unsatisfied Requirements above.
- **F2 (misleading AI Insights mock)** — `/insights` is live-navigable, fully mocked, and visually indistinguishable from a real feature. Needs a product decision: gate it or label it "coming soon" before shipping v1.0.
- **F3 (uncommitted, unprotected AI chat endpoint)** — `app/api/leads/chat/route.ts` + `app/[tenant-slug]/leads/agente/page.tsx` are fully wired, functional, and **uncommitted**. The route has no role/tenant scoping and no rate limiting — any authenticated user can send an arbitrary prompt to the shared Anthropic API key. This is outside REQUIREMENTS.md's scope entirely (not part of any phase's plan) but is a live security gap in the running app today. Needs a decision: harden and commit, or remove.
