interface StatePayload { tenantId: string; tenantSlug: string; customerId: string; nonce: string; iat: number }

export function verifyState(state: string): StatePayload | null   // null on bad signature or expiry

```typescript
export const runtime = 'nodejs'
export async function GET(req: NextRequest): Promise<Response>
// 401 (JSON) if no user; 403 (JSON) if get_user_role() RPC errors/null or role not in {super_admin, tenant_admin};
// 400 (JSON) if customerId query param missing/invalid;
// 307 redirect to https://accounts.google.com/o/oauth2/v2/auth?... on success
```

app/api/google-ads/callback/route.ts (created in Plan 03):
```typescript
export const runtime = 'nodejs'
export async function GET(req: NextRequest): Promise<Response>
// verifies state; exchanges code at https://oauth2.googleapis.com/token; writes Vault; upserts ad_accounts;
// always returns a 3xx redirect (never JSON) — to /${tenantSlug}/settings on success/known-tenant error, to / on unverifiable state
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → GET /api/google-ads/connect | Authenticated user initiates OAuth; customerId + (for super_admin) tenant params cross here |
| Google → GET /api/google-ads/callback | Cross-site top-level GET redirect carrying `code`, `state`, or `error` — untrusted until `state` HMAC is verified |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing/Tampering | OAuth `state` param | mitigate | oauth-state.test.ts asserts verifyState rejects tampered signature, tampered payload, and expired iat — the executable spec for the HMAC+expiry mitigation (impl in Plan 02) |
| T-07-02 | Elevation of Privilege | GET /connect tenant scope | mitigate | connect-route.test.ts case 7 asserts tenant_admin's tenantId/tenantSlug come from getClaims(), never from the query string |
| T-07-04 | Information Disclosure | token handling in callback | mitigate | callback-route.test.ts mocks fetch and never asserts on logged secrets; Plan 03 enforces no-logging — this test establishes the behavioral surface without token echo |
| T-07-05 | Tampering (data integrity) | missing refresh_token | mitigate | callback-route.test.ts case 5 asserts a response without refresh_token is a hard error (google_error=no_refresh_token), never a silent partial connect |
</threat_model>
