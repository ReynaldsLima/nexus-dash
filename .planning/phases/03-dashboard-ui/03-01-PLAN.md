    - aggregateRollups soma total_spend/total_clicks/total_impressions/total_conversions/total_conv_value de todas as linhas
    - roas = total_conv_value / total_spend; se total_spend === 0 → roas = 0
    - cpa = total_spend / total_conversions; se total_conversions === 0 → cpa = 0
    - ctr = (total_clicks / total_impressions) * 100; se total_impressions === 0 → ctr = 0
    - calcDelta(110, 100) → { absolute: 10, pct: 10 }
    - calcDelta(50, 0) → { absolute: 50, pct: null } (guard divisão por zero — Pitfall 7)
    - computePriorRange(from, to): priorTo = from - 1 dia; priorFrom = priorTo - duração; mantém o mesmo número de dias
    - computeChannelSplit: dado total google e total meta, retorna { google: { value, pct }, meta: { value, pct } } onde pcts somam 100 quando soma > 0, e ambos pct = 0 quando soma === 0
  </behavior>
  <action>

- `export type RollupRow = { total_spend: number; total_impressions: number; total_clicks: number; total_conversions: number; total_conv_value: number }`
- `export type AggregatedKpis = { spend: number; roas: number; cpa: number; ctr: number; conversions: number; clicks: number; impressions: number }`
- `export function aggregateRollups(rows: RollupRow[]): AggregatedKpis` — reduzir somando, derivar roas/cpa/ctr com guards `denom > 0 ? ... : 0`. Usar `Number(r.total_spend)` etc. para coagir strings numéricas.
- `export function calcDelta(current: number, prior: number): { absolute: number; pct: number | null }` — `pct = prior > 0 ? ((current - prior) / prior) * 100 : null`.
- `export function computePriorRange(from: Date, to: Date): { priorFrom: Date; priorTo: Date }` conforme RESEARCH.md Pattern 6 (durationMs = to - from; priorTo = from - 86400000; priorFrom = priorTo - durationMs).
- `export function computeChannelSplit(googleSpend: number, metaSpend: number): { google: { value: number; pct: number }; meta: { value: number; pct: number } }` — total = google+meta; pct = total > 0 ? (value/total)*100 : 0.
