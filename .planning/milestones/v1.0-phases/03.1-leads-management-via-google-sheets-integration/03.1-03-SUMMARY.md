## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Vercel production build broken by uncommitted pre-existing files**
- **Found during:** Task 2 checkpoint verification (live production test)
- **Issue:** `lib/leads.ts` and `app/api/leads/route.ts` had never been committed to git (flagged as deferred item 3 in `03.1-01`/`03.1-02` execution — written outside the GSD flow). The moment this plan's `page.tsx` change was pushed, the Vercel Turbopack build failed with "Module not found: Can't resolve '@/lib/leads'" because the build environment only has committed files.
- **Fix:** Committed exactly `lib/leads.ts` and `app/api/leads/route.ts` (nothing else untracked) as a standalone `fix` commit.
- **Files modified:** `lib/leads.ts`, `app/api/leads/route.ts`
- **Verification:** Vercel production build succeeded after the commit; feature deployed and reachable at `/lukseg/leads`
- **Commit:** `572b5ed`

**2. [Rule 1 - Bug] Stale cached read masked a successful write as a silent failure**
- **Found during:** Task 2 checkpoint verification (live production test)
- **Issue:** `GET /api/leads` had a pre-existing `next: { revalidate: 60 }` fetch cache with no tag. Changing a lead's status and navigating back to the leads page within the 60s window showed the old status, even though the Sheets write had already persisted (confirmed directly against the live Google Sheet cell).
- **Fix:** Tagged the cached fetch per-tenant (`leads-${tenantSlug}`) in `app/api/leads/route.ts` and called `revalidateTag(tag, 'max')` in the `PATCH /api/leads/[id]/status` route immediately after a successful Sheets write. Also fixed `revalidateTag()`'s call signature for Next.js 16's new required second argument, and added a `next/cache` mock to `tests/unit/leads-status-route.test.ts` (matching the existing pattern in `tests/tenants.test.ts`) since `revalidateTag` requires a request-scoped cache context unavailable under plain Vitest.
- **Files modified:** `app/api/leads/route.ts`, `app/api/leads/[id]/status/route.ts`, `tests/unit/leads-status-route.test.ts`
- **Verification:** Full test suite green (15 files, 118 passed); reload after a status edit in production now reflects the new value immediately
- **Commit:** `30ecaa9`
